# 微信读书网页版 AI 朗读

这是一个 Tampermonkey / Violentmonkey 用户脚本（v0.4.0），给 `https://weread.qq.com/web/reader/*` 阅读页加一个悬浮朗读控制条。

功能：

- 自动提取当前章节正文，按句子分块朗读
- 适配微信读书 canvas 阅读器：正文不是普通 DOM，脚本从阅读器内部 Vuex 加密正文条目、`tempContent` 明文和 `preRender` 临时 DOM 快照里提取
- 保留普通 DOM 阅读页的 fallback
- 支持暂停、继续、停止、语速 0.75x 到 2x
- 支持选择系统中已安装的中文语音
- `重试` 按钮：重新从阅读器内部状态提取当前章节正文
- `章节续读`：翻到下一章后自动继续朗读；不勾选则在切换章节时停止
- 设置会保存在浏览器本地

## 说明

微信读书网页版的新版阅读器用 canvas 绘制正文，页面上没有可滚动、可高亮的正文 DOM，所以脚本不在原页面做句子高亮和滚动跟随，只按内部提取出的文本逐句朗读。

脚本会监听阅读器预渲染阶段短暂出现的明文 DOM，并从新版 `ReaderRenderContent` 组件和旧版横向阅读器组件里读取解密后的章节 HTML，因此 Chrome / Edge 均可使用。

## 安装

1. 浏览器安装 Tampermonkey 或 Violentmonkey 扩展。
2. 打开 `微信读书AI朗读.user.js`，扩展会自动识别并弹出安装页。
3. 安装后打开微信读书网页版阅读页，右下角会出现 `朗读` 控制条。

如果浏览器没有自动识别，也可以手动新建脚本，把文件内容粘贴进去保存。

## 音色说明

脚本使用浏览器内置的 Web Speech API。Windows 上推荐用 Edge 浏览器，系统自带微软晓晓、云希等神经网络中文音色，效果接近真人朗读。

如果 Chrome 里没有中文音色，可以：

- 换用 Edge 打开微信读书
- 或在 Windows 的“设置 > 时间和语言 > 语音”里安装中文语音包

## 想接更高级的云端 AI 音色

浏览器内置音色零配置可用。若要接 OpenAI TTS、Azure Speech、MiniMax 等云端神经音色，需要把当前脚本改成“把章节文本发送到 TTS 接口、播放返回的音频”的版本，通常还需要本地代理或浏览器扩展解决跨域和密钥保存问题。这个升级版可以单独做。
